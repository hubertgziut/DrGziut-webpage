# DrGziut — strona internetowa

Nowoczesna, responsywna strona Huberta Gziuta — specjalisty chirurgii plastycznej.

## Stack

- React 18 + TypeScript
- Vite 5
- własny responsywny design system CSS
- interfejs PL / EN z przełącznikiem języka

## Uruchomienie lokalne

```bash
npm install
npm run dev
```

Aplikacja będzie dostępna pod `http://localhost:5173`.

## Produkcyjny build

```bash
npm run build
npm run preview
```

## Zawartość

- strona główna: hero cinematic, filozofia, procedury, proces, zespół, opinie, FAQ, formularz;
- podstrony: chirurgia plastyczna, medycyna estetyczna, filozofia/metoda, klinika, konsultacja, cennik, kontakt;
- obrazy to ilustracje koncepcyjne / generowane AI — nie przedstawiają pacjentów ani efektów zabiegów;
- treści medyczne mają charakter informacyjny. Przed publikacją formularz wymaga podłączenia do bezpiecznej obsługi zgłoszeń i uzupełnienia dokumentów prawnych (RODO, polityka prywatności, regulamin).
